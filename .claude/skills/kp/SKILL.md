# КП по чертежу — методика студии

Задача: из PDF дизайн-проекта получить (1) обмерный файл, (2) черновик КП,
(3) список допущений и вопросов. КП клиенту НЕ отправляется — только Алексею
на утверждение.

## Источники правил (читать перед счётом)

**Единственный источник правды — `CLAUDE.md` в корне репозитория**,
разделы «Тарифная модель» и «Правила обсчёта объёмов по чертежам».
Правила там свежее и полнее, чем в ФАКТАХ и чем были в этом скилле.
Если что-то здесь расходится с CLAUDE.md — прав CLAUDE.md.

- Эталон **кода правил обсчёта**: `документы/kp-generator/build_kp_novovilenskaya.py`
  (зафиксирован с владельцем 26.08.2026).
- Эталон **вёрстки КП**: `документы/kp-generator/build_kp_losika.py`;
  печать в PDF — `topdf.js`.
- Числа (ставки, себестоимость, курс): `документы/kp-generator/costs.py`,
  `build_memo_manager.py`.
- Эталон обмерного файла: `документы/объекты/лосика-53-обмер.md` —
  **структуру брать, правила по дверям-невидимкам и скрытым зонам
  в нём устарели** (посчитан до 26.08).

## Конвейер

### 1. Техразбор PDF
pymupdf: число страниц, текстовый слой (`get_text()`), форматы страниц.
Текста нет (CorelDRAW) → рендер 300 dpi + тайлы 3×2 с перекрытием 6 %.
Текст есть → извлекать напрямую вместе с координатами.

### 2. Опознание состава
Обзорная сетка миниатюр всех листов (40 dpi, 12 на лист). Найти: ведомость
чертежей, план-схему отделки стен (легенда площадей по типам!), план полов
и плинтусов, план потолков (опуски), план заполнения дверных проёмов,
развёртки помещений. Визуализации и электрику пропустить.

### 3. Извлечение
С больших комплектов — параллельные агенты по листу (схема-JSON: стены,
ширины×высоты, отделка, проёмы, плинтус, подоконник, dimensions_verbatim,
uncertainties) + финальный агент-критик: арифметика цепочек, сверка сумм
с легендой, противоречия листов. Малые комплекты — читать напрямую кропами
300 dpi.

### 4. Достройка недостающего
Высоты окон и не проставленные ширины — фотограмметрия: рендер 300 dpi,
внешняя рама по тёмным линиям, калибровка мм/px по проставленной ширине
ЭТОГО ЖЕ окна (масштабы листов различаются!). Обязательные самопроверки:
подоконник + окно + ниша/полоса = чистовой потолок; розетки на отм. 900/300;
сходимость двух окон одного листа. Глубины откосов: двери 0,1 м если
не заданы; окна — спросить замер у Алексея (не выдумывать).

### 5. Правила счёта — по CLAUDE.md, кратко
- Ведомости дизайнера не верить: считать постеночно по развёрткам,
  чужие покрытия вычитать, потолки сверять с листом потолков.
- Работа: шире 0,5 м и **ровно 0,50 м — квадратами**; уже 0,5 м —
  погонными по длине. Материал — всегда вся площадь в м². Запас 5 %.
- Откос окна = ширина + 2×высота (низ под подоконником не считать).
- **Дверь-невидимка: откосы ЕСТЬ** — скрытые, ~0,1 м, длина 2H + W
  (5,1 п.м. на 700×2200): работа погонными, материал длина × 0,1.
  Размеры стены — по пунктиру короба (800 при полотне 700 → по 50 мм
  с боков погонными по высоте; полоса над проёмом — погонными).
- Полотно двери — отдельной позицией: материал по площади стороны,
  работа €45/м² стороны (700×2000 — €63 за сторону).
- Скрытые зоны: за зеркалами, тумбами, навесной мебелью санузлов —
  считаем; за зеркалами во всю стену и встроенными шкафами (белая
  штриховка) — не считаем.
- Короб инсталляции — как обычная стена. МДФ-фасады: материал по
  ставке стен, работа €45/м² + €5/п.м. торца по периметру.

### 6. Цена
Тарифная модель из CLAUDE.md (евро): фикс до 20 м²; база 20–35 м²;
линейная кривая 35–100 м²; дно от 100 м²; двери; расходники от €80;
примыкания, уклон, трап, трещины. В адресном КП — евро как эквивалент
и рублёвая сумма по курсу НБ РБ; оплата в BYN на день оплаты.
На витрине сайта — только рубли.

### 7. Выход
1. `документы/объекты/<объект>-обмер.md` — по структуре эталона: потолки,
   двери, отделка по помещениям, откосы, полосы, габариты стен, вычисленные
   размеры с методикой, дыры проекта, противоречия, расход материала
   (нормы из ФАКТЫ раздел 1), смета м²+м.п., цена по прайсу.
2. Черновик КП — генератор по образцу `build_kp_novovilenskaya.py`
   с вёрсткой `build_kp_losika.py` (дизайн UNICORE из CLAUDE.md),
   PDF через `topdf.js`, страница ровно 1123 px по высоте.
3. **Список допущений и вопросов** — первым сообщением Алексею. Всё,
   что не прочитано, вычислено с допущением или противоречиво в проекте.
4. Закоммитить обмер в репозиторий.
