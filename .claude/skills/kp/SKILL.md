# КП по чертежу — методика студии

Задача: из PDF дизайн-проекта получить (1) обмерный файл, (2) черновик КП,
(3) список допущений и вопросов. КП клиенту НЕ отправляется — только Алексею
на утверждение.

## Источники правил (читать перед счётом)

- `документы/ФАКТЫ-ПРОИЗВОДСТВА.md` — правила смет (раздел «Правила смет»)
  и действующий прайс (раздел 2а). Прайс и правила брать ТОЛЬКО отсюда.
- Эталон готового обмера: `документы/объекты/лосика-53-обмер.md`.

## Конвейер

### 1. Техразбор PDF
pymupdf: число страниц, текстовый слой (`get_text()`), форматы страниц.
Текста нет (CorelDRAW) → рендер 300 dpi + тайлы 3×2 с перекрытием 6 %.
Текст есть → извлекать напрямую вместе с координатами.

### 2. Опознание состава
Обзорная сетка миниатюр всех листов (40 dpi, 12 на лист). Найти: ведомость
чертежей, план-схему отделки стен (легенда площадей по типам!), план полов
и плинтусов, план потолков (опуски), план заполнения дверных проёмов,
развёртки помещений. Визуализации и электрику пропустить.

### 3. Извлечение
С больших комплектов — параллельные агенты по листу (схема-JSON: стены,
ширины×высоты, отделка, проёмы, плинтус, подоконник, dimensions_verbatim,
uncertainties) + финальный агент-критик: арифметика цепочек, сверка сумм
с легендой, противоречия листов. Малые комплекты — читать напрямую кропами
300 dpi.

### 4. Достройка недостающего
Высоты окон и не проставленные ширины — фотограмметрия: рендер 300 dpi,
внешняя рама по тёмным линиям, калибровка мм/px по проставленной ширине
ЭТОГО ЖЕ окна (масштабы листов различаются!). Обязательные самопроверки:
подоконник + окно + ниша/полоса = чистовой потолок; розетки на отм. 900/300;
сходимость двух окон одного листа. Глубины откосов: двери 0,1 м если
не заданы; окна — спросить замер у Алексея (не выдумывать).

### 5. Правила счёта (из ФАКТЫ, дублирую якорь)
- Плоскости ≥ 0,5 м — м². Всё уже 0,5 м — погонные метры: откосы, полосы
  под окном / над проёмом, узкие простенки вдоль окон и дверей.
- Площади полос, ушедших в м.п., ВЫЧЕСТЬ из квадратуры (не задваивать).
- Откос окна = ширина + 2×высота (низ под подоконником не считать).
- Двери скрытого монтажа — откосов нет; полотна могут отделываться
  (позиция «двери» прайса, по одной стороне).
- За встроенной мебелью — ВОПРОС Алексею: по проекту (полный периметр)
  или по факту открытых. Показать обе цифры.
- Материал считается по полной площади (плоскости + площадь откосов),
  работа — м² + м.п.

### 6. Цена
Прайс из ФАКТЫ 2а (евро): база / формула скидки 35–100 м² / дно от 100 м²;
фиксы до 20 м²; двери; примыкания; расходники. Курс НБ РБ — оговорить,
что оплата по курсу на день оплаты.

### 7. Выход
1. `документы/объекты/<объект>-обмер.md` — по структуре эталона: потолки,
   двери, отделка по помещениям, откосы, полосы, габариты стен, вычисленные
   размеры с методикой, дыры проекта, противоречия, расход материала
   (нормы из ФАКТЫ раздел 1), смета м²+м.п., цена по прайсу.
2. Черновик КП: таблица по помещениям (материал м² × цена; работа м²+м.п.
   × цена; двери; расходники; итого €; эквивалент BYN). Формат — как
   КП № 18082026 (kp-losika.html).
3. **Список допущений и вопросов** — первым сообщением Алексею. Всё,
   что не прочитано, вычислено с допущением или противоречиво в проекте.
4. Закоммитить обмер в репозиторий.

## Запреты
- Не отправлять ничего клиенту/наружу; в наружные документы не включать
  марки материалов (Remmers, BS 3000) и нормы расхода.
- Не гадать молча: любое допущение — в список вопросов.
- Не менять прайс и правила по ходу счёта — только из ФАКТЫ.
