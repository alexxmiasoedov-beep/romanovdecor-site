# Арбитраж Фонбет ↔ Полимаркет

Сканер расхождений цен между линией Фонбета и спортивными рынками
Полимаркета. Личный инструмент, к сайту UNICORE отношения не имеет.

## Запуск

```bash
python3 arb_scan.py                          # скан на 2 дня вперёд
python3 arb_scan.py --days 3 --min-edge 4    # горизонт 3 дня, перекосы от 4%
python3 arb_scan.py --books --bankroll 100   # проверка реальным стаканом + раскладка ставок
python3 arb_scan.py --json out.json          # полный результат в JSON
```

Только стандартная библиотека Python 3, никаких зависимостей.

## Как это работает

1. **Фонбет** — неофициальный JSON линии
   `line01i.bk6bba-resources.com/events/list?lang=en&scopeMarket=1600`
   (те же данные, что грузит сайт; ~2000+ прематч-матчей). Факторы
   921/922/923 = П1/Х/П2.
2. **Полимаркет** — `gamma-api.polymarket.com/events?tag_slug=<лига>`,
   берутся рынки `sportsMarketType: moneyline`. Футбол — три Yes/No
   рынка (П1/Х/П2), теннис — один рынок на двоих.
3. **Матчинг** — по названиям команд (fuzzy, порог `--min-sim`) и
   времени начала (±3 часа).
4. **Математика**:
   - маржа Фонбета снимается пропорционально: `честно_i = (1/кф_i) / Σ(1/кф)`;
   - *чистый арбитраж*: каждый исход покрывается дешёвой стороной
     (цена Yes на ПМ или 1/кф на ФБ); если сумма < 1 — гарантированная
     прибыль, печатается раскладка ставок на `--bankroll`;
   - *перекосы*: разница цены ПМ и безмаржевой вероятности ФБ ≥
     `--min-edge`% — кандидаты на value-сделку.

## Важные оговорки

- Цены из gamma-api — **mid**, а не цена исполнения. Всё, что найдено
  без `--books`, обязательно перепроверять с ним: он тянет best ask из
  стакана CLOB и обычно убивает половину «находок».
- Перекос «ПМ дороже» = кандидат на покупку **No**; цена No оценивается
  как 1 − Yes, реальный ask по No может отличаться.
- Арбитраж предполагает ставку на Фонбете **руками** — автоматизация
  ставок запрещена правилами букмекера. Скрипт только читает линию.
- Кросс-площадочный «арбитраж» несёт нерыночные риски: разные правила
  расчёта (отмена матча, отказ игрока, ОТ в хоккее/баскетболе),
  задержка исполнения, лимиты. Реальный порог входа — прибыль от ~2%,
  а не 0,3%.
- Эндпоинты неофициальные: не поллить чаще раза в 30–60 сек, формат
  может измениться без предупреждения.
