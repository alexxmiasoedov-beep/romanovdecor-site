# Знак UNICORE

Исходники дизайн-канваса с вариантами логотипа.

## Что здесь

| Файл | Артборд |
|---|---|
| `Main.dc.html` | Направление А — монограмма U в квадрате |
| `Letter.dc.html` | Направление Б — только слово, на игре UNI/CORE |
| `Core.dc.html` | Направление В — слои и ядро, срез материала |
| `Lock.dc.html` | Направление Г — знак плюс слово, замки |
| `Mono.dc.html` | Одна краска: версии для заявки в НЦИС, выворотка, тест размером |
| `Apply.dc.html` | Применение: этикетка ведра, визитка, шапка сайта |
| `canvas.json` | Раскладка артбордов на холсте |

Правки вносятся в эти файлы. Собранный холст `unicore-logo.html` —
результат сборки, он не хранится в репозитории: весит больше двух мегабайт
и пересобирается из исходников одной командой.

## Пересобрать

```bash
node "<база скилла design>/seed-canvas.mjs" \
  --template "<база скилла design>/payload.template.html" \
  --out unicore-logo.html \
  --title "UNICORE — знак" \
  --artboard Main.dc.html --artboard Letter.dc.html \
  --artboard Core.dc.html --artboard Lock.dc.html \
  --artboard Mono.dc.html --artboard Apply.dc.html \
  --canvas canvas.json
```

Опубликованный холст живёт по адресу
`https://claude.ai/code/artifact/6dd0e59c-cae3-472e-ad66-f613a2f0cc4e` —
пересборка публикуется туда же по тому же пути файла.

## Палитра

Та же, что во всех документах студии: графит `#2c2c2c`, золото-охра
`#b8965a`, бежевые `#f5efe2` и `#cbbf9f`. Шрифт Geologica.

## Что доделать перед печатью

- имя на визитке стоит заглушкой `[ИМЯ]`
- `unicore.by` на макетах напечатан, но домен ещё не зарегистрирован
- финальные файлы для типографии и заявки нужны в кривых, чтобы знак
  не зависел от наличия шрифта Geologica
