# Документы Romanov Decor Studio

## коммерческие-предложения/
- `КП-Евгений-микроцемент.pdf` — КП для заказчика Евгения (санузлы, коридор, лестница, гостиная).
  Итого $23 044,20 со скидкой на материал. Незаполненные поля: телефон и фамилия заказчика,
  адрес объекта, имя менеджера.

## памятки/
- `Памятка-по-ценам.pdf` — внутренний документ: базовые цены, шкала по объёму,
  надбавки, дополнительные работы, правило скидки, пример расчёта.

## kp-generator/
Генератор PDF. Требуется Python 3 (openpyxl) и Node с playwright-core.

```bash
export SC=<путь к папке со скриптами>
python3 build_kp5.py  && node topdf5.js   # КП
python3 build_memo.py && node tomemo.js   # памятка
```

- `build_kp5.py` — КП из файла замеров, стиль калькулятора сайта
- `build_memo.py` — памятка по ценам
- `замеры-Евгений-v2.xlsx` — исходные замеры объекта

## Ценовая система (кратко)

| | 0–20 м² | 21–45 | 46–80 | 81+ |
|---|---|---|---|---|
| Стены | $1 300 пакетом | $40 + $24 | $38 + $22 | $36 + $20 |
| Полы | $1 500 пакетом | $50 + $25 | $48 + $23 | $46 + $21 |

Шкала прогрессивная: ставка применяется к метрам внутри своего диапазона.
Себестоимость материала: стены $15/м², полы $25/м².

**Обмер:** материал — вся площадь; работа — стороны от 0,5 м в м², меньше 0,5 м в погонных метрах.

**Надбавки:** потолки и лестница — работа +20%. **Фиксы:** дверь $100/шт + материал,
гидроизоляционная лента $100.

**Дополнительные работы:** примыкание стена/пол $3/пог. м, с паркетом и ламинатом $10/пог. м,
с плиткой $7/пог. м, ремонт трещин $5/пог. м, уклон к трапу в одну сторону $200,
конверт к трапу $300, герметизация трапа $50, уклон в котельной $200.
