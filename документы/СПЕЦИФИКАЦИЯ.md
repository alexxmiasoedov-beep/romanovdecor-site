квадратный метр: на узких поверхностях нанесение идёт медленнее.

20 м² — добираем до двадцати по той поверхности, которой больше.

# 4 · Вёрстка PDF

Все документы собираются одинаково: Python генерирует HTML, Playwright
печатает его в PDF. Никаких библиотек вёрстки — чистый HTML с инлайновыми
стилями.

## 4.1 Пайплайн

```bash
export SC=/путь/к/рабочей/папке
python3 build_memo_manager.py          # пишет $SC/kp/memo-manager.html
node topdf2.js                          # печатает $SC/kp/Прайс-под-ключ.pdf
```

Скрипт печати:

```js
const { chromium } = require('playwright-core');
(async () => {
  const b = await chromium.launch({ executablePath: '/opt/pw-browsers/chromium' });
  const p = await b.newPage({ viewport: { width: 794, height: 1123 }, deviceScaleFactor: 2 });
  await p.goto('file://' + process.env.SC + '/kp/memo-manager.html', { waitUntil: 'networkidle' });
  await p.waitForTimeout(800);
  console.log('высота:', await p.evaluate(() => document.body.scrollHeight), '(A4=1123)');
  await p.pdf({ path: process.env.SC + '/kp/Прайс-под-ключ.pdf', format: 'A4', printBackground: true });
  await b.close();
})();
```

**Проверка сходимости:** `document.body.scrollHeight` должен быть ровно
**1123** — это высота A4 в CSS-пикселях. Больше — документ уехал на вторую
страницу, меньше — внизу пустота.

## 4.2 Каркас страницы

```html
<style>@page{size:A4;margin:0}*{margin:0;padding:0;box-sizing:border-box}body{width:210mm}</style>
```

Корневой блок:

```
width:100%; min-height:1123px; padding:18px 30px 14px;
background:#fff; color:#2c2c2c;
font-family: Geologica, Arial, sans-serif;
display:flex; flex-direction:column
```

Подвал прижимается `margin-top:auto`.

Шрифт подключается ссылкой:
`https://fonts.googleapis.com/css2?family=Geologica:wght@300;400;500;600;700&display=swap`

## 4.5 Формат чисел

- Десятичный разделитель — **запятая**: `€48,50`
- Разряды тысяч — **неразрывный пробел**: `€1 120`
- Целые суммы без копеек: `€175`, а не `€175,00`
- Символ валюты **перед** числом, без пробела
- Площадь — `141,54 м²`, погонные — `95,86 м.п.`

## 4.6 Структура «Прайса под ключ»

Порядок блоков сверху вниз:

1. **Шапка** — логотип, название, справа «Прайс под ключ» и «евро за м² · август 2026»
2. **Два блока в ряд:** «Минимальный выезд» (тёмный) и «Если поверхностей две» (бежевый)
3. **Цены** — таблица 7 колонок: площадь + 3 по стенам + 3 по полам
4. **Формулы** — тёмный блок, моноширинное начертание, множители подсвечены `#b8965a`
5. **Границы и объём** — таблица в две пары колонок
6. **Фиксированные позиции** — таблица в две пары колонок
7. **Подвал** — контакты слева, «Цены в евро, оплата по курсу на день оплаты» справа

Внутренняя памятка добавляет к этому разделы «Расход и фасовки»
и «Себестоимость и маржа — не отдавать», и печатается с пометкой
«Внутренний документ — клиенту не отдаём».

## 4.7 Структура КП

1. Шапка с датой и номером КП
2. Заголовок «Коммерческое предложение»
3. Два блока в ряд: «Заказчик» (бежевый) и «Исполнитель» (тёмный)
4. **Спецификация** — таблица 8 колонок: наименование, материалы (объём,
   цена, сумма), работы (объём, цена, сумма), итого. Ширины колонок:
   `21% · 8.5% · 10.5% · 10% · 15% · 10.5% · 10% · 14.5%`
5. Строка «ИТОГО К ОПЛАТЕ» справа, 17px, `#b8965a`, под ней сумма в рублях
6. Три плитки: Материалы · Работы · Всего (третья тёмная)
7. Блок условий с левой золотой полосой `border-left: 2px solid #b8965a`
8. Подвал

Ячейки КП крупнее, чем в прайсе: `padding: 5.5px 6px`, `font-size: 10px`,
`height: 19px`.
